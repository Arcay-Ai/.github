# Security policy

If you find a security vulnerability in any Arcay AI repository, **do not open a public issue or pull request**.

Email **support@tryarcay.ai** with:
- the affected repository and file or URL
- steps to reproduce
- the impact you expect

We aim to acknowledge reports within 3 working days.

## For team members
- Never commit secrets, API keys, `.env` files or client data. Use the cloud provider's secret store.
- If a secret is committed by mistake, rotate it immediately. Deleting the commit is not enough.
